# AG 横向 Gx/Gy 与同一状态传播

2026-10-21。映射 beam_dynamics_6d.py、beamline_sim.py、runner.py。

目的：恢复用户批准的 Kelisani 2023 SC Gx/Gy，取消原来强制固定横向发射度的近似。仍是原论文的高斯、方向间约化闭合，不新增粒子或非高斯模型，不保证逼近 PIC 所有高阶相关。

## 方程与单位

固定参考 γ、近轴、当前正式圆束与线性外力范围。每方向 u 的 σu [m]、νu=dσu/ds [1]、θu=sqrt(<u'²>) [1]：

```
Mu = σu²(θu²-νu²) [m²]
σu'=νu; νu'=(θu²-νu²)/σu + Fu; θu'=Gu
Mu'=2σu²(θu Gu-νu Fu)
εn,x/y = βγ sqrt(Mx/y) [m]
εn,p = βγ³ sqrt(Mz) [m]  # 纵向动量坐标，不能混用
```

从原论文 Eq.(15),(18) 独立相减，令 X=νx αx/(σxσz)、Y=νy αy/(σyσz)、Z=(1-pbar0²)νz αz/(σxσy)，得到

```
Mx'/Mx = -2fb/γ (3X+Y+Z)
My'/My = -2fb/γ (X+3Y+Z)
Mz'/Mz = -2fb/γ (X+Y+3Z)
fb=[e/(mc²)] Ne e/(8π√π ε0) [m]; pbar0=βγ
```

例如 θx Gx-νx Fx 的自项为 -3fb νx αx(θx²-νx²)/(γσxσz)，交叉 y 项为 -fb νy αy(θx²-νx²)/(γσyσz)，z 项为 -fb(1-pbar0²)νz αz(θx²-νx²)/(γσxσy)。领先项和 αxx/xy/xz 对应项抵消。y 由 x/y 对称得出，z 保留已经验证的配对式。独立测试直接转写未化简 Eq.(18)/(19)，不以这三个化简式互相自证。

Ne=0 或均匀椭球线性 SC 时三方向面积变化率为零。现有加速兼容项继续含 -2D Mu，D=γ'/(γ³β²)，但正式验收仍限定γ'=0，不宣称加速坐标已验证。线性独立外力 F=a u 贡献 θG=νF，面积不变；RF 在同一状态上作矩变换。一般非圆束完整耦合不在此状态闭合的验收范围。

## 数值表示和兼容

内部演化三组 σ、ν、M，M 用 10⁻¹² m² 缩放，防止默认绝对容差淹没相空间面积。拒绝有限负面积、非法束宽和失败积分，不通过裁剪掩盖。

公共 history 由12列扩为14列：前12列顺序不变，追加 eps_nx [m]、eps_ny [m]。从已演化历史重建 Beam6D 必须传完整行；正式 runner、分段RF和绘图均消费追加列。只给旧11列状态的旧调用仍使用显式提供的横向发射度常数，无法恢复未传入的历史信息。元数据与文档须明确版本。

## 验证与限制

检查未化简论文 G、SC 局部矩恒等式、x/y交换、无SC解析漂移、线性元件相空间面积、分段传播和重建、RF零强度/可逆，以及正式保存输出。动态 Gx/Gy 的影响一般是高斯闭合中的相对论高阶修正，可能很小、也可能降低投影发射度；不能人为强制单调增长或为了匹配 PIC 添加经验项。

来源：Kelisani 等，Phys. Rev. Applied 19,054011 (2023)，Eq.(3),(7),(15)-(20)。https://journals.aps.org/prapplied/pdf/10.1103/PhysRevApplied.19.054011

## 本轮补充数值边界

1000 fC 完整束线在新 RF 下曾触发 RK45 试算阶段 σz<0（s≈0.503304 m），不是已接受轨迹的负束长。默认 RK45 现在复用 SciPy 步进器，只在试算状态越界时从未改变的已接受状态减半试算步；不裁剪状态、不放宽 rtol/atol。单次步进最多32次缩步，无法恢复则明确失败。该包装依赖已核对的 SciPy 1.13.1 RK45 提交状态顺序；更换积分方法时保持原有非法状态拒绝，不自动套用该机制。另用 y'=-10y 的指数正解与故意过大初始步独立验证拒步后解析精度。

另发现现有 α 表只覆盖 kx,ky∈[0.01,100]，而本轮100 fC完整AG束线输出样点最大比例约376.7。此处旧算法仍截到表边界，本轮没有凭经验扩展力公式。正式结果新增 sc_alpha_table_domain，并在启用高斯SC且样点越界时发出 RuntimeWarning。该记录只能发现输出样点越界，不能证明所有内部积分阶段均未越界。涉及此区域的完整AG数值不作物理精度验收；短漂移检查仍需按各自参数解释。
