# AG 纵向状态与 Gz 演化：Physics Note

日期：2026-10-16。映射：`longitudinal_state.py`、`beam_dynamics_6d.py`、`runner.py`、`beamline_sim.py`。

## 1. 目的、依据与研究者选择

修复 SC 后的包络状态与 RF 使用的相关矩不一致。原实现的 SC 改变 νz，却不更新 σδ 与 Czδ；零强度 RF 因重算 νz 而产生跳变。

用户于本轮明确选择：补齐论文纵向 Gz 演化；初态以两模型共享的 σz、σδ 为准，推导 AG 的纵向发射度。本次只补齐纵向 Gz，横向仍保留已有固定发射度近似，不宣称完整实现论文所有 F/G 方程。

来源：M. D. Kelisani, S. Barzegar, P. Craievich, S. Doebert, *Six-Dimensional Beam-Envelope Equations: An Ultrafast Computational Approach for Interactive Modeling of Accelerator Structures*, Phys. Rev. Applied 19, 054011 (2023)，[正式 PDF](https://journals.aps.org/prapplied/pdf/10.1103/PhysRevApplied.19.054011)，Eq. (3), (6), (7), (10), (17), (20)。

## 2. 坐标、量纲与约束

束线位置 s [m]，束内坐标 ζ [m] 朝束头为正，δp=Δp/p₀ [1]。恒定参考能量、近轴窄动量分布一阶上，ζ′=δp/γ²。源码 `Beam6D.p0` 是无量纲 βγ，不是 SI 动量。

定义 σ=√⟨ζ²⟩ [m]、ν=σ′ [1]、θ=√⟨ζ′²⟩ [1]，全部二阶矩去中心：

```text
A = σ² [m²], B = σδ² [1], C = ⟨ζδp⟩ [m]
C = γ²σν
B = γ⁴θ²
M = σ²(θ²−ν²) = (AB−C²)/γ⁴ [m²]
εs = √M [m]                    # (ζ,ζ′) 的几何发射度
εn,p = βγ³√M [m]               # (ζ,δp) 的归一化发射度
```

εn,p 是配置 `epsilon_nz_mm_mrad` 历史名字所对应的量；它与论文斜率坐标下的 βγ εs 相差 γ²。1 mm·mrad=10⁻⁶ m。不能互换这两种定义。

协方差须满足 A>0、B≥0、AB−C²≥0。初态检查拒绝非有限数、非正 σ、γ≤1、负展宽/发射度以及实质性非半正定协方差。相关性与发射度约束用相对容差 10⁻⁸ 检查。浮点半正定边界仅容许 64 倍机器 epsilon 的相对舍入量，并明确标记；不隐藏有限的负方差。

## 3. Gz 与已有 Fz 的配对推导

恒定 γ 时，二阶矩给出：

```text
σ′ = ν
ν′ = (θ²−ν²)/σ + Fz
θ′ = Gz
M′ = 2σ²(θGz−νFz)
```

原有 Gaussian Fz 为论文 Eq. (17)。将 Eq. (20) 的 θGz 与 νFz 相减，领先项、含 θx²/θy² 的项及相应交叉系数抵消，可得：

```text
K = 3νz(1−p̄₀²) αz/(σxσy) + νx αx/(σxσz) + νy αy/(σyσz)
θGz − νFz = −(fb/γ)(θ²−ν²) K
M′/M = −2fb K/γ
fb = [e/(mc²)] Ne e/(8π√π ε₀), p̄₀=βγ
```

`longitudinal_sc_area_log_rate` 实现这个化简式；现有 Fz、α 插值和物理电荷来源不重写。对 M=0，直接用 M′=rate·M，不计算除零的 M′/M。该式一般不为零，保留论文 Gz 对纵向发射度演化的作用；不是固定发射度补丁。

独立验证使用未化简的 Eq. (20)，在 100 keV、5 MeV、正负 νz 与非零横向斜率的状态下计算 θGz，再与现有 Fz 加配对项比较。参考和实现共用 α 表，因此这项验证核对 Gz 转写/代数，不验收 α 表绝对误差或高斯近似。

当前纵向外力线性于 ζ，θGe=νFe，故其贡献不改变 M；正式螺线管 Fez=0，RF 使用薄透镜。保留的均匀椭球模型内部力线性，SC 对 M′ 的贡献为零，但仍更新 C 与 σδ。

## 4. 数值表示与 RF

内部只积分一组纵向状态 (σ,ν,M)，加上原横向状态、相关量与 γ，共 10 个活动变量。M 以 (1 μm)²=10⁻¹² m² 为单位缩放，使原绝对容差不淹没很小的相空间面积；这是显式单位选择，不是调参。

每次计算力和输出时推导：

```text
θ = √(ν²+M/σ²)
σδ = γ²θ
C = γ²σν
```

公开历史仍为原来的 12 列，以保持调用兼容；σδ 与 C 是派生列，不再独立积分。原 `nu_delta` 作为兼容占位输出 0，不视为额外物理自由度。`eps_nz` 不再决定固定纵向压力；从历史状态重建 Beam6D 时更新为协方差计算值。

求解器继续 RK45，默认 rtol=10⁻⁸、atol=10⁻¹⁰；活动变量与缩放改变后，旧自适应步序不再保持位级相同。检查 success、完整终点、有限值、正束宽和非负 M；失败显式报错。加速回调的既有阻尼系数保留，M′ 还含 −2DM，但本轮正式物理验收限定 γ′=0，加速坐标仍需单独推导验证。

RF 定义 H [m⁻¹]，δp⁺=δp⁻+Hζ：

```text
C⁺ = C⁻+Hσ²
B⁺ = B⁻+2HC⁻+H²σ²
ν⁺ = ν⁻+Hσ/γ²
σ⁺ = σ⁻, M⁺ = M⁻
```

计算 B⁺ 时使用 B−C²/A 与新相关项之和，降低聚焦附近的相消误差。先验证输入，再对 H=0 返回副本；不一致的旧 SC 输入会报错，零强度分支不能隐藏上游缺陷。验证包括真实 SC 演化后的 H=0、H 后接 −H、协方差矩阵 LΣLᵀ 和行列式守恒。

旧连续 chirp 分支存在坐标与量纲问题。本次正式路径不使用它；非零连续 chirp 回调现在明确报错并要求使用薄透镜，避免继续静默执行未定义物理。历史 helper 的其他坐标债务仍有登记。

## 5. 初始输入、输出与调用位置

正式 `AG.runner.run_from_config` 使用共享 σz、σδ，初始 C=ν=0，推导 εn,p。YAML 的历史 `epsilon_nz_mm_mrad: 0.02` 保留不改，值及未被采用的事实写入 meta；不再与共享动量展宽同时控制演化。

当前有效值为 0.0196651503343 mm·mrad。`longitudinal_check='warn'/'error'` 控制冗余输入约束提示/拒绝；两种策略都拒绝不可能的状态。正式 CLI 与验证适配使用同一个 driver。

原输出量及单位保留。AG 专属纵向记录写入 `meta.longitudinal_evolution.history`：C、ν、θ、chirp [m⁻¹]、(ζ,ζ′) 几何发射度 [m]、(ζ,δp) 归一化发射度 [mm·mrad]，以及相关性约束残差与浮点边界计数。`beamline_sim.compute_emittance` 的 `eps_geo_z` 改为实际斜率坐标几何发射度，不再返回输入常数。

## 6. 本轮验证与误差边界

- 新增专项：解析相关漂移、独立 Eq. (20)、SC 局部矩方程、RF 恒等/可逆/行列式、非法输入、积分器失败、CLI 保存、椭球线性极限与零发射度边界。
- 原有回归与新增检查共 8 组，在隔离副本运行，原报告/检查点不被重写；验收阈值未放宽。
- 一致初态、100 keV、100 fC、0.4 m Gaussian 漂移：σδ 从 10⁻⁴ 演化至约 0.001522313，C 与 γ²σν 一致，H=0 的 ν 相对变化由 −99.7032% 变为 0。
- 同案例收紧至 rtol=10⁻¹⁰、atol=10⁻¹²，σz、νz、σδ 末值相对变化均小于 9×10⁻⁹；不是完整收敛扫描。
- 0.05 m 小型 PIC 对照仅用于诊断：seed42、N=5000、33³、dz=1 mm；σz 相差约 1.89%，σδ 相差约 11.47%。没有据此认定 SC 完整验收。

横向 Gx/Gy 尚未恢复，横向发射度仍固定。Gaussian 高阶截断、非高斯尾部、α 插值、PIC 抽样/网格收敛、有限 RF 腔、加速坐标及非对齐 OCELOT RF 事件仍有未验收部分。

新参考记录 `validation/baselines/ag-longitudinal-gz-20261016.json` 明确保存旧值与迁移原因；旧基线文件不覆盖。无 SC AG 数组改变来自初态/纵向模型修正与积分表示变化，不能继续要求旧 hash；OCELOT 与共享配置保持原样。
