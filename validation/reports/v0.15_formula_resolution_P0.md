## 2. P0-1 Eq.3 Damping

### 2.1 Original paper equation（两次独立 PDF 提取，一致）
```
σ''u + [γ0·γ'0 / (γ0²·p0²)]·σ'u = F^e_u + F^s_u + F^ε_u     (Eq.3)
```

### 2.2 Variable definitions（论文原文）
- γ0：参考粒子能量；β0：归一化速度；**p0 = γ0β0**（"momentum p0 = γ0β0"，论文原文明确）
- 独立变量：z0（参考粒子位置）
- γ'0 = dγ0/dz0

### 2.3 Algebraic reduction
```
D_paper = γ0·γ'0 / (γ0²·p0²)
        = γ0·γ'0 / (γ0²·(γ0·β0)²)    代入 p0=γ0β0
        = γ'0 / (γ0³·β0²)
```

### 2.4 Current AG implementation（beam_dynamics_6d.py:953-957）
```
D_AG = γ·γ' / (γ²·β²) = γ' / (γ·β²)
```

### 2.5 Ratio
```
D_AG / D_paper = [γ'/(γβ²)] / [γ'/(γ³β²)] = γ²
```
数值 benchmark（γ'=10 m⁻¹ 任意）：
| 场景 | D_paper | D_AG | 比值 |
|---|---|---|---|
| 100 keV（γ=1.1957） | 1.946e+01 | 2.783e+01 | **1.430 = γ²** |
| 5 MeV（γ=10.785） | 8.041e-03 | 9.353e-01 | **116.3 = γ²** |

### 2.6 Verdict
**P0-1: CONFIRMED（数学不一致，差 γ²）——但当前生产 beamline 无加速（γ'=0），阻尼项恒为 0，对现有全部验证结果零影响。** 若未来加入加速段（γ'≠0），AG 纵向/横向包络阻尼将比论文弱 γ² 倍。
保留限定：论文 Eq.3 分母"γ0²·p0²"依赖 PDF 文本提取（两次一致）；**建议目视 `/tmp/kelisani_Eq1-6.png` 终裁**。

## 3. P0-2 Alpha_xx / Alpha_yy

### 3.1 Original Eq.24-25（PDF 文本提取）
```
αxx = ∫₀^∞ 3k_x⁴·s·ds / [2√((s²+k_x²)⁵(s²+k_y²)(s²+1))]   (Eq.24)  ← 文本含孤立的 "2"
αyy = ∫₀^∞ 3k_y⁴·s·ds / [2√((s²+k_x²)(s²+k_y²)⁵(s²+1))]   (Eq.25)  ← 文本含孤立的 "2"
```
对比 Eq.21-23/26-29（αx/αy/αz/αzz/αxy/αxz/αyz）：文本中**无**孤立 "2"。**但 PDF 文本流无法判定 "2" 是分母系数还是排版噪声**——需目视。

### 3.2 Current implementation（beam_dynamics_6d.py:104-111）
```
f_axx = 3·k_x⁴·s / √((s²+k_x²)⁵(s²+k_y²)(s²+1))     （无 1/2）
f_ayy = 3·k_y⁴·s / √((s²+k_x²)(s²+k_y²)⁵(s²+1))     （无 1/2）
```

### 3.3 Full call chain
```
compute_all_alpha (:77) → _build_alpha_cache (:150, log 网格 15×15)
  → get_alpha_interpolators / alpha_at (:185)
  → _space_charge_forces (:382: axx,ayy = alpha['xx'],alpha['yy'])
```
