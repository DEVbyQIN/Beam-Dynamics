# C1：RF 独立高斯数学参考

2026-10-24。对应 `rf_gaussian_reference.py`、`rf_reference_study.py` 和
`test_rf_gaussian_reference.py`。它们属于验证层，不是第三条生产路线。

## 目的与边界

问题是：规定入射分布和现有有效薄透镜映射后，AG 与 OCELOT 是否分别实现了各自方程，
线性化自身会产生多大统计量差异？参考代码不导入生产 RF 或诊断模块。
它不证明真实腔体准确、不检验 SC、不为完整束线给出精度保证。
RF 设备及薄透镜假设的文献背景见 `shared/rf_model_physics_note.md`；
[Franssen & Luiten, 2017](https://arxiv.org/abs/1703.05258) 的场积分及参考坐标
需要与设备约定对应，不能用本次数学验收代替标定。

## 定义与方程

- 束线位置为 s [m]；束内坐标 ζ=−βcΔt [m]，OCELOT tau=cΔt [m]。
- 项目 δ=Δp/p0，无量纲。当前一阶适配 δ=p_oc/β；p_oc=ΔE/(c p0)。
- 固定参考 β、γ 和总能量 E [eV]。V 为有效积分电压 [V]，包含设备映射所需的渡越效应；
  按当前约定，能量增益的数值以 eV 表示，电荷符号已包含在有效相位/电压约定内。
- ω=2πf [s⁻¹]，q=ω/(βc) [m⁻¹]，a=V/(β²E)，φ [rad]。

现有模型规定：

```text
ΔErelative = V [sin(φ−ωΔt)−sinφ]
δ+ = δ− + g(ζ),   g(ζ)=a[sin(φ+qζ)−sinφ]
H = a q cosφ;     AG 用 δ+ = δ− + Hζ
```

扣除的是理论参考粒子的能量增益，不是每次有限云的实测均值。
本参考严格验证这条规定映射；动量转换没有因此成为全阶相对论变换。
φ 使用实际输入 3.1416，不能偷偷替换成 π；前者有微小非零质心增益。

令入射为零均值联合高斯，A=σζ² [m²]、B=σδ²、C=Cov(ζ,δ) [m]，
要求 W0=B−C²/A≥0。设 t=q²A，则由高斯特征函数得到：

```text
mean(δ+) = a sinφ [exp(−t/2)−1]
h+ = C/A + H exp(−t/2)                [m⁻¹]
C+ = A h+
N = a² { (sin²φ/2)[1−exp(−t)]²
           + cos²φ exp(−t)[sinh(t)−t] }
W+ = W0 + N
B+ = W+ + A h+²
D+ = A W+                            [m²]
σδ+ = sqrt(B+)
σδ,unc+ = sqrt(W+)
εnz+ = βγ sqrt(D+)                    [m]，乘 10⁶ 输出 mm·mrad
```

h 是去质心最小二乘线性 chirp；W 是去除此线性相关后的残余方差。
N 是正弦弯曲留在线性残差中的部分，不是新增随机热噪声。
推导用 E[δ|ζ]=(C/A)ζ，因而 C 的演化和初始相关的交叉项也被保留。

线性参考用 h+=C/A+H、W+=W0、D+=D0。非线性正弦剪切保持精细相空间面积，
却不要求由二阶矩定义的 RMS 投影面积不变；不能据 εnz 增长断言违反刘维尔定理。
小 t 时 N=a²[(sin²φ/2)t²+(cos²φ/6)t³+…]，在零交叉附近主项是三阶。

## 独立数值方案与误差预算

1. `gaussian_reference(method='quadrature')` 从时间域增益直接积分。
   标准正态积分区间为 (−∞,−4,0,4,+∞)；用 mpmath 45/65 位各算一次。
   先求均值与回归斜率，再积分残差平方，避免用大数相减获得微小非线性方差。
2. `method='analytic'` 独立使用上述特征函数结果；`expm1` 和高精度运算处理小 t。
   不调用生产 `relative_energy_gain_eV`、`coefficients` 或 `particle_diagnostics`。
3. `method='linear'` 给出切线矩变换，用于核对 AG 实现。
4. `time_kick_on_cloud` 直接计算时间正弦；与生产使用的稳定三角恒等式分开。
   对实际同一云逐粒子比较，然后独立重算中心矩和回归残差。
5. 本卡的高精度参考一致性目标 1e−25；AG/同云粒子矩的相对差目标 1e−10；
   点粒子 δ 的绝对残差目标 1e−14。近零均值按输出 σδ 缩放，不能除以趋零均值。
   这些只属于新增数学检查，不修改旧物理阈值。
6. AG 捕获状态的 W=B−C²/A 可能有消减误差，须同时记录状态内的 εnz。
   3000 μm 压力例的矩残差约 3.74e−11；这是明确的浮点条件影响，未据此放宽目标。

## 生成器总体与有限云

本机 OCELOT 26.06.1 的默认 Gaussian tau 生成器使用 ±5σ、500 个 PDF 节点、
梯形累计 CDF 和线性逆插值。因此诱导总体是 499 个分段均匀区间；
每段概率正比 (fi+fi+1)Δxi/2，并非严格无限高斯，也不是分段线性密度。
源码和 SHA 在报告的 `generate_parray_source.txt`、`invert_cdf_source.txt` 与 `execution.json`。

`tabulated_sampler_reference` 逐段独立 Gauss–Legendre 8/16 点积分。
`sampler_interval_reference` 在 65 位精度下以 sinc 区间积分及其导数独立求矩，
并核对小均值与非线性残差。前者阶数一致性和与后者的主要量一致性目标 1e−12；
不是生产 CDF 累加的位级复刻。其真实总体 RMS 比名义 σ 高约 59.492 ppm。
直接积分描述生成器出口；本次把 RF 入口设为 s=0，故可直接使用。
若 RF 前有漂移/SC，不得沿用这个未经推送的入口总体。

误差分层：无限高斯→生成器总体是确定的输入近似；生成器总体→有限云是统计差别；
独立同云映射→生产更新是实现残差。另单列线性/正弦近似及各路径参考常量差异。
不能把所有人口总体与样本的差异都叫数值错误或随机噪声。

单云误差条用影响函数的 IID/CLT 渐近 95% 半宽。对中心化 X=ζ−meanζ、
Y=δ−meanδ，h=E[XY]/A，R=Y−hX，W=E[R²]：

```text
IF(h) = XR/A
IF(σδ) = (Y²−B)/(2 sqrt(B))
IF(sqrt(W)) = (R²−W)/(2 sqrt(W))
IF(ε) = ε/2 [(X²−A)/A+(R²−W)/W]
半宽 = 1.95996398454 std(IF,ddof=1)/sqrt(N)
```

需等权 IID、有限四阶矩、非退化协方差；不要求输出高斯。
不能直接用于 quiet-start、强制矩匹配、相关粒子或不等权云。
本次 runner 在 seed+1 下独立重采 δ，未启用 quiet-start 或矩匹配。
三工况复用同 seed，因此不是三个独立重复实验；逐量区间也不是联合置信保证。
本轮不以此声称多种子收敛或完整系统误差界限。

## 正式路径和冻结运行

`rf_reference_study.py capture --out ABS` 调用正式 `AG.run_shared.main` 与
`GPT模拟.ued_beamline_v2.main(step=3)`，每组各一次，共六次。
只读包装器捕获真实 RF 调用前后；不另建初态或追踪循环、不替换力公式、不修改粒子。
实际 JSON 由正式输出函数保存，并查验配置 SHA、开关、事件一次且在 0 m、样品面 22 mm。
`capture` 对已存在的 runs/receipt 拒绝重跑；`analyze` 只读冻结快照重算参考。

本卡：σζ=30/300/3000 μm；100 keV、σδ=1e−4、C=0；Veff=30 kV、
f=2.856 GHz、φ=3.1416；SC OFF、无磁透镜、RF 横向 OFF；N50000、seed42、dz1 mm。
300 μm 是这张卡规定的 RF 入射束长，不是默认完整束线 400 mm 处实测入射束长。
3000 μm 是数学压力例，其大动量调制不用于证明一阶动量转换或真实设备适用。

瞬时 RF 状态由事件快照判定。已有生产 history[0] 在本例存在事件侧区别：
AG 是 RF 后，OCELOT 是 RF 前。相同 s=0 不等于同一事件侧，不能直接相减。
22 mm 保存结果含后续漂移；不拿它直接对照入口的瞬时 RF 解析矩。
本轮记录这项输出语义边界，未擅自改生产采样。

## 常量差异与验收解释

AG RF 系数沿用 shared β/γ 及 SI 静能得到的总能量；粒子侧总能量沿用
511 keV 静能；AG 核心状态又有既有的静能数值。此时 H_AG/H_OC−1 约 +2.07034 ppm，
状态 βγ_AG/βγ_OC−1 约 +1.12312 ppm。本轮显式保存并分开解释，未统一常量。

AG 实现对照其实际系数及状态归一化，OCELOT 对照其实际系数及同云；
纯模型近似比较则两侧严格使用同一套 shared/粒子约定。
各自通过数学检查不能改称“参考定义已完全统一”。
