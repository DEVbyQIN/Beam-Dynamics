# AG 纵向 Gz 与 SC→RF 状态统一

日期：2026-10-16。

## 原因与物理选择

SC 改变包络变化率，但另存的 Czδ、σδ 未收到相应更新；RF 用错误相关矩重设 νz。2026-10-05 的只读推导已定位，本轮用户授权实施，并明确选择论文 Gz 演化及共享束长/动量展宽优先。

## 修改

- 新增 `AG/longitudinal_state.py`：定义、初态与协方差检查、纵向诊断。
- `AG/beam_dynamics_6d.py`：以论文 Eq. (17)/(20) 化简配对演化 M，σδ/C 从同一组独立状态推导；RF 使用同一协方差；拒绝非法状态和积分失败。
- `AG/runner.py`：采用已选择的输入优先级，记录历史输入和真实纵向输出；CLI/验证适配共用。
- `AG/beamline_sim.py`：纵向几何发射度由实际状态计算，明确斜率坐标。
- 新增专项并纳入 `run_all`；相应更新退出码测试。阻尼测试的原人工初态存在 C/ν 不一致，修正初态，保留 NU_TEST、参考阻尼公式和 10⁻¹² 原阈值。
- 新数值参考另存 JSON；电荷语义测试读取新参考，保留原 10⁻³ μm 的绝对检查阈值。
