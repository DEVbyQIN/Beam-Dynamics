# 共同 RF 有效薄透镜

2026-10-21。映射 shared/rf_model.py、AG/runner.py、GPT模拟/ued_beamline_v2.py。

## 定义、方程、范围

本次按用户批准的两路线行为统一修复。s 为束线距离 [m]，tau=cΔt [m]，ζ=-βtau [m]（头正），δp=Δp/p0，p_oc=ΔE/(cp0)≈βδp。频率 f [Hz]，k=2πf/c [m⁻¹]，相位 φ [rad]；电子负电荷和腔极性已吸收到相位定义，φ≈π 为纵向压缩零交叉。

V_eff [V] 定义为沿参考轨道积分后的有效单频电压幅值，包含实际渡越时间效应；不再自动乘入任意 TTF，也不从 V_eff/L 推断真实峰值场。真实硬件的电压标定与轴向场图仍未知。

电子能量增益 g(Δt)=eV_eff sin(φ-ωΔt)。正式模型扣理论参考增益 g(0)，不扣粒子样本均值：

```
ΔE_rel/e = V_eff[sin(φ-k tau)-sinφ] [eV]
Δp_oc = (ΔE_rel/e)/(β E_total,eV)
H = V_eff k cosφ/(β³ E_total,eV) [m⁻¹]
AG: δp+ = δp- + Hζ
```

额外的 1/β 来自物理束内长度到到达时间的转换。原 kζ 对100keV不成立。参考能量固定，此模型不模拟共同加速；离开零交叉时的数学调制测试不等于完整加速腔验收。AG 采用纵向一阶矩映射，粒子侧保留时间正弦曲率。

横向共同近似为轴对称、近轴一阶、弱场近似恒速、完整积分区间端部轴向场消失、穿腔横向位移近似不变的积分薄透镜。真空 Maxwell 方程给 Er=-r∂sEz/2、Bθ=r∂tEz/(2c²)；沿轨迹积分并消去端部场，得到

```
Δ(p_x/p0)=K_perp x, Δ(p_y/p0)=K_perp y
K_perp = -H/(2γ²) [m⁻¹]
```

两路线均在同一入口使用中心相位的横向线性 kick；不再使用 AG 区间分布力或无相位的旧 K。这是已有有效模型的明确统一，非真实有限腔体场重建；未包含完整高阶或全阶辛 RF 映射。默认横向开关仍关闭。

100keV 下 H≈-17.8374 m⁻¹，K≈+6.23823 m⁻¹；纵向压缩对应此积分模型的横向散焦。22mm 腔中的有限长度效应仍需实际场验证。作用平面保留原项目入口约定。

## 数值、事件和验收

相对能量差用 -2V sin(k tau/2)cos(φ-k tau/2) 稳定计算。AG 调用既有协方差薄透镜更新；横向同时更新包络相关斜率并保持线性相空间面积。无SC追踪步在RF入口切分；有SC时用原生Navigator的零长边界进程定位入口，SC计数仍完全由原生调度控制。RF事件逐实例记录 nominal/actual。

独立验收从 Δt、场积分和能量变化出发，检查30/100/1000keV、零V、参考粒子、相位反号、小束长极限及入口位置。横向使用光滑紧支撑轴对称合成场的径向电力和磁力数值积分，不能以目标K公式与自身比较。
