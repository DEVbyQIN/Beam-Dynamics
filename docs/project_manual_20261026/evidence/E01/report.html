3 · RF：修的是坐标转换，不是调参

束内坐标是 ζ=−βcΔt。一个粒子晚到多少时间，决定它遇到多少 RF 相位；将这件事写成束内长度时，必须除以 β。100 keV 的 β≈0.548，因此旧公式漏掉的因子约为1.824。

ΔE_rel/e = V_eff [ sin(φ − ωΔt) − sinφ ]
H = ∂δp/∂ζ = V_eff (2πf/c) cosφ / (β³ E_total,eV)
横向共同薄透镜：K = −H / (2γ²)

V_eff 指有效积分电压。没有实际轴向场图和硬件电压定义，不能再任意乘一个渡越时间因子。固定参考模型扣去理论参考粒子的共同能量变化；它不是完整的任意相位加速腔。

同一默认电压/相位，无 SC修改前样品束长修改后样品束长

末端变长不代表修复变差：更强的调制会改变压缩腰位置；原参数不能继续被当作已验证的最佳压缩配置。本轮没有重新优化电压。真实有限长度腔体仍需场图、端场与电压标定验证。

4 · SC：补齐方程以后，哪些差异还在？

AG原来把横向发射度固定住；现在恢复论文 Gx/Gy，让它随同一个状态演化。这里的变化很小：50 mm、100 fC案例中横向发射度由0.08变为约0.079999915 mm·mrad。这说明“补齐横向G”与“让AG获得PIC的非高斯展宽”是两件不同的事。

Mu = σu² (θu² − νu²)
Mx / My / Mz 同时演化 → 推导瞬时发射度、σδ 和相关矩
线性外力 / 无SC / 均匀椭球线性SC：面积变化率为零

7 · 下一步只先解决一件事

先解决 α 系数的表内精度与越界处理，再扩展强压缩比较。

顺序具体工作为什么验收依据
1审查现有α积分与插值表，建立独立积分误差预算；给越界明确失败或有依据的计算策略。默认完整AG轨迹已实际越界，继续用它判断物理会混入未定量误差。各向对称极限、x/y交换、对独立积分的误差与范围；默认轨迹无静默越界。
2在有效表域内给短SC工况建立适用范围，按束宽/束长/展宽/发射度分别判定。尺寸接近不能保证展宽和发射度可信；不能只给一个总PASS。固定初态、网格/步长/粒子数控制，加更多独立种子和误差预算。
3确认真实RF电压含义与轴向场，再决定是否需要有限长度模型。本轮修复的是有效薄透镜的一致性；设备对应关系仍缺输入。用实验/电磁场图验证相位、有效积分电压、端场和横向作用。
之后清理配置几何检查、原型入口与环境锁；一般耦合/加速/非高斯升级另行立项。先修影响当前研究结论的环节，避免同时膨胀模型。每项独立、可回退、明确适用域。

这次不建议重跑所有历史模拟，也不建议立即新增第三种模型。主问题已从“入口是不是各算各的”缩小为“现有AG近似及其系数计算在什么范围可信”。
