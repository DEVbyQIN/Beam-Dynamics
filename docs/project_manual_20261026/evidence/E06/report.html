1 · 做了什么，为什么这样改

原正式入口传入字符串 "SecondTM"，当前库会静默退回一阶默认方法；原输出却宣称使用二阶。这一接入错误已修复。

进一步核查发现，本机 OCELOT 26.06.1 的磁透镜虽然允许选择 SecondTM，其二阶张量却与同长度漂移完全相同，缺少必要的磁透镜色差项。因此采用已独立核查的最小方案：

部分当前实际实现验收依据与限制
漂移、RF保长body、零长锚点显式 SecondTM质量壳与自由飞行公式的二阶展开、误差阶数；它仍是截断近似
磁透镜显式 TransferMap对参考粒子的一阶硬边界模型，与独立Hamiltonian矩阵指数一致；不含色差与高阶像差
RF既有入口手工kick公式与事件位置未改；不是原生有限腔场
SC既有原生SpaceCharge调度公式、网格和调度未改；本轮短例只验执行契约

当前准确名称是“漂移二阶、磁透镜一阶”，不能称整线二阶。正式builder构造后检查活动 tms；低层自建束线保留调用者方法并如实记录 caller_supplied，不会冒充正式策略。

来源：官方方法接口、官方漂移说明、本机源码与Astra high独立复核。没有修改库源码或新增生产物理模型。

3 · 独立数学检查说明了什么

漂移参考直接从自由粒子能量—动量关系和到达时间推出，不把AG或OCELOT自身张量当标准。将测试输入跨度减半，一阶误差约降为1/4，二阶误差约降为1/8，符合应有的截断阶数。原生二阶展开与独立公式逐项一致。

坐标、关键公式与磁透镜缺项

原生 a=p_x/p0、b=p_y/p0、q=ΔE/(p0c)，τ=cΔt，γ=E0/(mc²)，β=sqrt(1-γ⁻²)。固定参考、正向无场传播L：

w = sqrt(1+2q/beta+q²-a²-b²)
Delta x = L*a/w
Delta y = L*b/w
Delta tau = L*((1/beta+q)/w - 1/beta)

二阶展开包含能量与横向动量交叉项、角度平方飞行时间和能量平方飞行时间。100keV、L=0.1m时，测试跨度0.01/0.005/0.0025对应的二阶最大坐标误差分别约2.0171e-6/2.5600e-7/3.2248e-8 m；这些跨度是数学诊断输入，不是生产误差上界。

对参考动量的硬边界磁透镜，独立Hamiltonian生成的 exp(LA) 与原生一阶R相符。非零能量偏差时，x_out对x_in*q的必要二阶系数为 kL sin(2kL)/β；项目名义参数下约1.079677114，而库的该项为0。Astra中心差分得到1.07967711399，并观察到缺项残差按二次缩放。

只有均匀Bz的默认RK没有同样的出入口边缘场，不能直接替代当前硬边界透镜。完整公式、坐标与限制见Physics Note。
