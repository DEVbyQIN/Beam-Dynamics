先用普通话说清楚

α是一组由束团形状决定的几何系数，SC方程拿它们计算自作用力和发射度演化。旧程序先做了一张较稀的表，然后从表里插值；形状超出表格时，就一直使用边界值。

现在仍算同样的九个积分，只改了求积分的数值办法。两种物理模型、共享输入、RF和束线都没有变化。

推导采用 s=exp(u)，以对数形式计算九个正值积分，避免极端比例下乘积溢出；数值域只是算法本轮检验范围，不是物理模型适用范围。没有为了与PIC接近而调整系数、物理参数或旧阈值。

展开关键方程和来源
I = C ∫₀∞ s ∏a(s²+a²)^(-pa/2) ds，a=(kx,ky,1)
kx = σx/(γσz)，ky = σy/(γσz)
u = log(s)，区间 [log(min a)−18, log(max a)+18]
尾项相对界 ≤ 2^(P/2)[exp(−36)+exp(−(P−2)×18)]，P=5或7

九项系数与物理假设来自 Kelisani 2023 第6页 Eqs.(21)–(29)；数值变换和尾界为本次推导。RD交叉验证依据 SciPy的Carlson RD定义。完整表、证明、单位与算法见 Physics Note。
