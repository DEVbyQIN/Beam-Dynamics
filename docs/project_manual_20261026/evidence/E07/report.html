1 · 这一步具体查了什么

① 换坐标将不同到达时间的电子放到同一实验室时刻。
② 解场在共同参考系中，计算电荷分布产生的场。
③ 施加kick根据力和参考时长，更新每个粒子的动量。
④ 回坐标换回束线诊断使用的位置、时间和能差。

这四层不能只凭最后的束宽来判断。我分别用独立的高斯Coulomb积分、质量壳与自由飞行关系、全局矢量Lorentz投影作参考，再观察一次真实原函数的输入和输出。

2 · 公式没查出错，数值场仍然有误差

先把高斯电荷在每个网格单元中的总量用CDF差积分出来，排除随机粒子抽样，再对照连续分布的独立场。所选12个轴向点的最大相对差为：

电荷分布网格最大所测场误差
球高斯33³3.8196%
球高斯63³1.1047%
项目静止系尺寸33³3.8910%
项目静止系尺寸63³1.1535%

把沉积、插值和场boost一起接上，在专门对齐的确定性分布下，34³/64³所选点最大差为7.8248% / 1.9219%。另补非圆束、非轴向64³采样，六个点的矢量相对差约0.907%–1.854%，正负位置场反对称残差约7×10⁻¹⁵。

这些数字不能当作默认N50000、63³随机粒子模拟的误差保证。34/64是为对齐诊断选择的测试网格，源分布和采样点也固定；这里没有覆盖随机抽样噪声、全工况渐近收敛或整线误差传播。

因此本轮的完成条件是“明确各层数学关系与所测离散误差”。没有另设一个全局SC物理PASS阈值，也没有调整参数去追齐AG。

3 · kick 一致，不代表有限步完全精确

库使用一个由平均动量定义的共同速度来处理SC磁场和冲量。独立矢量参考确认了它的横向抑制因子、纵向力、参考时长及回坐标更新。

在匀强纵向场中，冻结参考时长的kick与“沿真实空间距离得到的精确电场功”存在有限步差别。本轮步长减半时，能量差约缩小4倍，符合应有的二阶局部残差。这个结果不能推出整个自洽追踪算法的全局阶数。

真实短例首步中，若在同一冻结场上改用各粒子的瞬时速度，力向量RMS与共同速度版本相差约0.0534%。这只是一个局部近似诊断，不能外推成发射度或整线误差上界；本轮没有替换该模型。
