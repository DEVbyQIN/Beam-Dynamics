RF开关在腔体前是否改变了入射

两组SC状态各自比较RF开/关在400mm前的记录，见analysis.json的upstream_RF_toggle。粒子新轨迹的初态六维指纹相同，复用轨迹的初态统计也核对。RF OFF的AG400mm是正式协方差插值，传播分段/采样网格与RF ON不同。SC开启时，AG此处εnz约有0.00612%的插值/分段差；粒子τ与p_oc入射数组仅有舍入量级差异。该项已记录，不把它装作严格同节点对照或混入约86%的模型差。
